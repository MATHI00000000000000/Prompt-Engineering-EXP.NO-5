**Naïve Prompt: **

A naive prompt is a straightforward question or command that does not include 
guidance, examples, or specific constraints, which may lead to less accurate or 
vague responses.

Example: 

** Naive prompt: **

“Explain blockchain.” 

**Basic Prompt: **

A basic prompt is a clear and direct instruction that includes the main task and 
some guidance, but may still lack depth, examples, or advanced structure. 
Example: 

** Basic prompt:**
